Помимо вызова какой-то функции, горутина может вызываться анонимно,тоесть так:
```go
package main

import (
	"fmt"
	"time"
)

func main() {
	go func() {
		for {
			fmt.Println("Анон")
			time.Sleep(100 * time.Millisecond)
		}
	}()
	time.Sleep(1 * time.Second)
}
```

Это нужно просто,чтобы выполнить функцию,которая всего 1 раз используется
