
Это базы данных,которые хранят данные в виде пар клю-значение,где ключ-уникальный идентификатор

![key-value_db|540](../../../картинки/key-value_db.png)

+:
- Скорость
- Простота модели хранения
- Значения могут быть любыми,включая формат json
-:
- Плохая масштабируемость связей и логики (чем больше данных - тем больше кода и сложнее становится взаимосвязь данных,падает производительность)
- Если надо работать сразу с несколькими записями,то будет потребляться больше времени и ресурсов по мере их обработки
- Отсутствие языка запросов; это в свою очередь значит что логика бд теперь лежит на коде,что его усложняет
