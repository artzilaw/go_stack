
Реляционными БД называют БД,в основе которых лежит реляционная модель; в такой базы данные структурированы в виде таблиц, которые содержат строки и столбцы

Этот набор таблиц называют отношениями,состоящими из столбцов и строк. Каждая строка представляет собой набор набор связанных значений, относящихся к одному объекту или сущности. Каждая строка можнь бвть помечена уникальным идентефикатором, который называют первичным ключом, а строки из нескольких таблиц могут быть связаны с помощью внешних ключей
![[relational_db.png]]

Особенности реляционных бд:
- Модель данных в реляционных БД определена заранее и является строго типизированной
- Данные хранятся в таблицах, состоящих из столбцов и строк
- На пересечении каждого столбца и строчки допускается только одно значение
- Каждый столбец проименован и имеет определённый тип, которому следуют значения со всех строк в данном столбце
- Столбцы располагаются в определённом порядке, который определяется при создании таблицы
- В таблице может не быть ни одной строчки, но обязательно должен быть хотя бы один столбец
- Запросы к базе данных возвращают результат в виде таблиц
